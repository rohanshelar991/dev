# Git Workflow

**Student:** Rohan Shelar

## Workflow
Working Directory → Staging Area → Local Repository → GitHub Remote

## Branches
- main: Main branch containing the merged work.
- feature-login: Branch used to develop the login feature.

## Commands
- git add: Stages file changes.
- git commit: Records changes in Git history.
- git push: Uploads commits to GitHub.
- git switch: Switches branches.
- git merge: Integrates changes from another branch.
- git log --oneline: Displays commit history.

## Verification
Use git branch -a, git log --oneline --all, and git status to verify the repository.
